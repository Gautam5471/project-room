# Getting help

- Setup questions and ideas: [GitHub Discussions](https://github.com/Uuriko/project-room/discussions).
- Reproducible bugs: [open an issue](https://github.com/Uuriko/project-room/issues/new/choose).
- Security vulnerabilities: use the private channel in [SECURITY.md](SECURITY.md).
- Contribution and review questions: [CONTRIBUTING.md](CONTRIBUTING.md).

Include your revision or release, operating system, runtime, expected behavior,
and a small reproduction using synthetic data. Remove secrets, invite links,
private messages, and personal filesystem paths from logs before sharing.
Never upload your database or connection directory.

You do not need a Project Room account to use GitHub support. Community support
has no guaranteed response time. If you find a workaround, add it to the
original thread so the next person can benefit.
